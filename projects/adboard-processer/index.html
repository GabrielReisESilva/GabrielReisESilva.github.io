Adboard Processer

EA Sports FC · FIFA · Internal desktop tool · 2023

A desktop tool for turning partner-supplied artwork, 100+ brands, leagues, and clubs, into pipeline-ready EA Sports FC adboards.

Role
Designer, engineer, owner (solo build)
Team
Electronic Arts · EA Sports FC / FIFA
Technical Stack
Electron · React · MUI · Node · ImageMagick
Released
2023 · Internal EA tool
What it does
  • Batch-process partner adboard artwork into pipeline-ready PNGs at the 64px pipeline height.
  • Convert any inbound image format to PNG, and normalize aspect ratio, including special long-adboard variants.
  • Detect and remove solid backgrounds, keeping the original background color as a hex value for downstream tooling.
  • Navigate a source directory tree with in-app preview, so operators can vet assets before saving.
  • Enforce naming standards on export, so downstream ingestion never sees mislabelled files.
Impact
  • ~80% reduction in per-adboard processing time across the team.
  • Bundesliga refresh, 87 adboards, original estimate 4 days, actual work 3 hours.
  • 100% of assets exported with correct background handling and naming standards after adoption.
  • Eliminated a recurring class of rework caused by manual mis-crops and inconsistent hex keying.
Why it exists
  • Adboard artwork arrived from 100+ external sources at inconsistent sizes, formats, and background treatments.
  • Manual per-asset prep in image editors was tedious, error-prone, and did not scale to season-refresh cadence.
  • Encoding the standard once in a tool made "correct" the default and freed operators from the checklist.
