ME2 Planet Scanner

Personal experiment · Unity · Shader · 2024

A shader recreation of Mass Effect 2's iconic planet-scanner UI, noise-driven response line, fully parameterized so I could tweak every visual behavior at edit time.

Role
Solo, personal project
Technical Stack
Unity · HLSL · Shader Graph
Released
2024 · Personal experiment
What it is
  • A shader reproduction of ME2's planet-scanner readout, complete with the noisy, responsive line graph.
  • Every visual parameter is exposed, noise frequency, response sharpness, decay, color blend, so I could dial in a version that matched the source and one that didn't.
  • Built as a design exercise about customization: high-fidelity mocks don't tell you how a system feels until it's in-engine.
Why I built it
Every hour spent making a system tweakable pays back tenfold in iteration speed. This was a small self-imposed constraint to practice that discipline outside of work.
