Digital Graffiti Wall

Samsung Valencia · Installation · 2021

A 6-meter interactive installation that lets an audience grab a digital spray can and paint on a shared wall, brandable, hands-on, and rebuilt-per-venue.

Role
Software Engineer
Team
Small studio, designer + engineer
Technical Stack
Unity · Windows · mobile · TCP / UDP · sensors + cameras
Released
2021 · Installation
What I did
  • Managed and tested every piece of the experience: Windows client, mobile app, and coordinating server.
  • Configured the Unity application and assisted with on-site install.
  • Built the Unity scene to client preference and adjusted mobile and server config per venue.
Constraints
  • Two-week schedule to understand, adjust, and ship a distributed system spanning desktop, mobile, server, cameras, and sensors.
  • 6-meter wide display with a 30% content cut-off band, camera viewport had to be reshaped to the visible area.
  • Remote design collaboration for art and lighting, iterating against the client's evolving direction.
  • Damaged hardware components and unpredictable venue conditions on install day.
  • Multiple communication protocols (TCP + UDP) between server, Windows app, and mobile clients.
What shipped
  • Software architecture aligned to the MVC pattern for maintainability across venues.
  • Camera render viewport reshaped for a multiple-display configuration matching the wall's visible area.
  • Lighting built with Unity reflection probes and baked lights.
  • Fail-safe server/client architecture handling both TCP and UDP protocols.
  • Schedule that flexed to on-site conditions without slipping the install date.
