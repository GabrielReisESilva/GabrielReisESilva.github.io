Stranger Things Main Menu

Personal experiment · Unreal Engine · 2026

An Unreal Engine recreation of the Stranger Things main menu, built from Sergey L's concept. Organic widget animations and a CRT screen-effect pass give it that old-TV vibe.

Role
Solo, personal project
Technical Stack
Unreal Engine · UMG · Materials · CommonUI
Released
2026 · Personal experiment
What it is
  • A Frontend recreation of Sergey L's Stranger Things menu design, rebuilt as a working, navigable menu in Unreal Engine.
  • Handled the navigation and interaction flow between menu screens and widgets.
  • Authored the materials for every Frontend element from scratch.
  • Added organic animations so the widgets feel alive and visually connected to one another.
  • Experimented with screen effects to land the CRT-TV look, scanlines, glow, and distortion.
Why I built it
A self-driven exercise to keep practicing UI craft and screen effects, and to turn a beautiful static concept into something that actually moves and responds in-engine.
