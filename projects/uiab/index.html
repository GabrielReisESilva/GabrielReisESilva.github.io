UIAB, UI Asset Builder

Unity Asset Store · Solo Release · 2024

A Unity editor tool that lets designers author sharp, resolution-independent UI directly in the engine, no Photoshop round-trip.

Role
Author & maintainer
Team
Solo / commercial release
Technical Stack
Unity · C# · HLSL · SDF · custom editor UI
Released
2024 · Unity Asset Store
What it does
  • Pixel-perfect shape primitives, rectangles, triangles, circles, polygons, and stars.
  • SDF-based rendering keeps details sharp at any scale.
  • Custom shader effects, drop shadows, inner shadows, inner and outer glows, driven by material parameters instead of baked textures.
  • Every property is animatable through Unity's Animator/Timeline.
  • Styles can be saved, loaded, and lerp-blended across the UI.
Why it exists
  • Real UI teams still ship raster PNGs and re-export every time the design system changes.
  • SDF-based authoring inside the engine collapses that loop into a single edit.
  • The tool is designed for its whole lifecycle: install, use, and maintain or extend.
