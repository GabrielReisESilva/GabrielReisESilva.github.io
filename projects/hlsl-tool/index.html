HLSL Stylized Graphics Tool

Personal experiment · Unity · Compute Shaders · 2023

A Persona 5-inspired stylized-graphics authoring tool for Unity, gradients, hard corners, and animated fills driven by compute shaders instead of texture assets.

Role
Solo, personal project
Technical Stack
Unity · HLSL · Compute Shaders · Custom Editor UI
Released
2023 · Personal experiment
What it is
  • An in-editor tool that lets artists author stylized graphics (gradients, geometric shapes, corner detail) directly in Unity without importing textures.
  • Runs on compute shaders so animation and color changes are effectively free at runtime.
  • Inspired by the visual language of Persona 5's UI, sharp geometry, acute angles, bold color blocking.
Why I built it
Follow-up exercise to a Udemy course on compute shaders, and an excuse to review the HLSL fundamentals I use every day at work through a fresh lens.
